# YOLOv2 / YOLO9000 精读导引

配合：`YOLOv2-中文译本.md` · 原文 arXiv:1612.08242

## 一句话抓住全文

> **YOLOv2 = 把 v1 的定位/召回短板补强（Better + Faster）；YOLO9000 = 用 WordTree 把分类大数据灌进检测（Stronger）。**

## 建议阅读顺序（约 1.5–2 小时）

1. **摘要 + 表 2**（先看从 63.4→78.6 是怎么涨的）  
2. **§2 Better 全部**（核心算法改进）  
3. **§3 Darknet-19**（骨干为何变快）  
4. **§4 WordTree + 联合训练**（概念重，可放慢）  
5. **实验表 3/4/5/7**（结论怎么写进调研表）

## 相对 YOLOv1，必须盯住的 6 个变化

| 点 | v1 | v2 |
|---|---|---|
| 框怎么来 | 直接回归 | **Anchor + 聚类先验** |
| 类别挂哪 | **格子级共享** | **每个 anchor 一套类别** |
| 中心怎么预测 | 相对格子 | 仍相对格子，但用 **σ 约束** + 先验宽高指数变换 |
| 特征 | 较粗 | **passthrough** 融入 26×26 细特征 |
| 输入尺寸 | 基本固定 | **多尺度训练**，一套权重多分辨率测 |
| 骨干 | GoogLeNet 风格 | **Darknet-19** |

## 读公式时的直觉

1. **聚类距离** `1−IOU`：先验要“像真实框”，不是欧氏靠近。  
2. **直接位置预测**：避免 RPN 无约束偏移把框甩到全图任意处 → 训练更稳。  
3. **WordTree 连乘**：细类概率 = 路径上各级条件概率之积；缺检测框时仍可靠上层（如 dog）泛化。

## 调研表可直接填的结论

**优点**
- 速度–精度可调（288→544）  
- 召回相对 v1 明显提升  
- 每个框独立分类，缓解“同格两类”问题  
- YOLO9000 开辟弱监督扩类路径  

**局限**
- COCO AP@[.5:.95] 仍落后顶尖两阶段/SSD512  
- 小目标仍弱（虽有 passthrough）  
- YOLO9000 对衣物等“COCO 无框可迁移”的类很差  
- 仍依赖 NMS；尚无 FPN 式系统多尺度头
