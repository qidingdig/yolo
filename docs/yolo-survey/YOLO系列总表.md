# YOLO 系列总表：优点 / 缺点 / 具体改进

> Living doc：后续问答会直接改本文件。  
> 写表原则：**说清“意味着什么”**；保留可指认的机制名；**少堆硬件名、绝对 FPS/AP 数字**（细节见各版译本）。  
> 缺点栏不把「有无正式论文」当作缺陷。

## 总表

| 版本 | 优点（意味着什么） | 缺点（卡在哪） | 相对前代改进（具体改了什么） |
|------|--------------------|----------------|------------------------------|
| **v1** | 处理很快；整图一次就算完，流程简单；较少把空背景误报成物体；换到油画等不同风格时也相对不容易崩 | 同一格子里难同时认出多个目标；框画得粗；小东西容易漏 | 开创：检测改成「整图一次回归」，不再先提一堆候选框再逐个分类 |
| **v2** | 比 v1 更少漏检、框更靠谱；一套模型能适应不同输入大小 | 网络仍偏浅；特别小、特别挤的目标还是弱 | 引入锚框（按数据聚类定形状）；把框中心约束进格子；加入细粒度特征通路；多尺度训练 |
| **v3** | 小目标明显好于前代；骨干更深更强；一个目标可带多个类别标签 | 框仍不如强两阶段贴；结构和超参开始变多 | 更深骨干；三个尺度同时预测；多标签分类 |
| **v4** | 速度和精度重新打到当时第一梯队；训练技巧整理成可复用配方 | 模块一多，调起来更费事；原工程栈不如后来 PyTorch 系好上手 | CSP 骨干、加强多尺度融合（PAN）、马赛克增强、更好的框损失等一整套训练/结构组合 |
| **v5** | 最好上手：模型大小有现成档位，训练到导出一条龙 | 经典版本仍靠锚框，换数据常要重配锚；后期精度上限被更新架构超过 | 把前代思想做成易用的缩放族、默认强增强和导出流程 |
| **v6** | 更面向产线：推理路径干净、吞吐高；量化部署更友好；分类和定位更对齐 | 重参数化/量化训练要额外配套；生态与常见 Ultralytics 流程不完全通用；大小模型结构不完全同一套 | 重参数化骨干与颈部、更轻的解耦头、无锚、新的标签分配与分类损失，并强调量化友好 |
| **v7** | 网络加深仍好训；同样实时要求下往往更准更省；可不靠大数据预训练打出强结果 | 「主头引导、粗细标签」等训练设计理解成本高；模型放大规则和普通加减通道不一样 | 改进层聚合（E-ELAN）；为拼接结构重做缩放；规划哪些层能用重参数化；用主检测头引导辅助头学习 |
| **v8** | 自定义数据更好用（少调锚）；分类和回归分开更清晰；检测/分割/姿态等任务一套接口 | 默认推理还要做重复框抑制（NMS）；极致参数效率后来被继续挖；尚未系统吃注意力 | 换更强特征块（C2f）；改为无锚解耦头；框用分布方式细修；多任务产品化 |
| **v9** | 深层训练更稳：该学的信息更不容易在网络里丢光；参数用得更值；推理不因此变慢 | 训练时多一条辅助路径，训练更重；多任务一体体验仍不如 v8/11 全家桶 | 可编程梯度信息（训练期辅助可逆分支）+ 更通用的高效层聚合骨干（GELAN） |
| **v10** | 推理可以不再依赖 NMS，端到端更干净、延迟更稳；同样精度下往往更轻更快 | 一对一预测头要和训练时的一对多监督对齐好；多任务覆盖面不如 Ultralytics 主线 | 训练双分配、推理只留一对一头；再系统性砍冗余（更轻分类头、更高效下采样与块设计等） |
| **YOLO11** | 相对 v8 更准更省；小目标/遮挡更有针对性；检测到分类等任务档位齐全，默认选型稳 | 默认仍走 NMS（不是「去后处理」那条线）；若只追论文峰值表，不一定压过后续实验向版本 | 换高效块（C3k2）、加部分空间注意力（C2PSA）、检测头分类侧更轻 |
| **v12** | 在实时速度约束下用上注意力，全局关系建模更强，小模型精度再抬一截 | 训练更吃显存；在 CPU 或部分导出路径上可能变慢；大模型要靠额外残差设计才好训 | 区域注意力降低注意力成本；用残差式层聚合稳定训练；工程上配合高效注意力实现 |
| **v13** | 不只看两两关系，还能挖多目标之间的高阶关联；复杂场景更有潜力；同时尽量保持轻量 | 结构更重，延迟通常高于同档实用基线；中大模型上再涨的收益变小 | 自适应超图增强相关；把增强特征分发回整网；用深度可分离块控复杂度 |
| **v14** | 专打「照片不像标准相机」：鱼眼、游戏画面、无人机、全景等能在同一框架里处理 | 通用榜单数字公开得少；场景变体多，数据和管线更重；目标不是单纯刷标准检测榜 | 场景路由增强、域对齐、视角条件、可变形/球形等模块，转向跨域非理想成像 |

## 相邻代：痛点 → 改动

| 从 → 到 | 前代卡点 | 后代怎么改 |
|---------|----------|------------|
| v1 → v2 | 同格冲突、框不稳 | 锚框、中心约束、细粒度通路、多尺度训练 |
| v2 → v3 | 小目标弱、网络偏浅 | 更深骨干、三尺度预测 |
| v3 → v4 | 训练散、融合弱 | CSP、PAN、马赛克、更好框损失等配方 |
| v4 → v5 | 难用、难部署 | 易用缩放族、默认增强、导出一体化 |
| v5 → v6 | 产线吞吐/量化不够顺 | 重参数化、解耦头、新分配/损失、量化友好 |
| v5/v6 → v7 | 加深难训、分配乱 | 更好层聚合、规划重参数化、主头引导学习 |
| v5 → v8 | 锚框麻烦、头任务绑太死 | 无锚、解耦、细框回归、多任务统一 |
| v8 → v9 | 深层信息易丢 | 训练期可编程梯度 + 新骨干 |
| v8/v9 → v10 | NMS 拖后腿、结构有冗余 | 推理去 NMS + 整体精简 |
| v8 → YOLO11 | 还想更省更稳 | 新块 + 空间注意力 + 更轻头 |
| YOLO11 → v12 | 缺高效全局建模 | 区域注意力进实时检测 |
| v12 → v13 | 相关建模停在两两之间 | 超图高阶相关 + 全管线分发 |
| * → v14 | 默认假设「标准针孔实拍」 | 跨域、多视角、畸变友好模块 |

## 选型速查

| 你更在意 | 更合适 | 一句话 |

| 把思想学顺 | v1 → v3 → v4 | 问题递进最清楚 |

| 训练理论/从零打榜思路 | v7 / v9 | BoF、PGI |

| 试验复杂关联 | v13 | 先当研究向 |
