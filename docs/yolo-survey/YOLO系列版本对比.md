# YOLO 系列版本对比：优缺点与具体改进

> 依据 `docs/yolo-survey/` 中 YOLOv1–v14 中文译本整理。  
> 目的：一眼看出**各代相对前代改了什么、强在哪、弱在哪、怎么选型**。  
> 注意：不同论文的 AP / FPS 测在不同 GPU、精度、是否含 NMS、是否预训练上，**不可把跨表数字当严格同台竞技**；下表以「机制对比 + 同文内相对提升」为主。

---

## 0. 先看总图：三代主线

```text
学术/结构主线（Darknet → WongKinYiu 等）
  v1 → v2 → v3 → v4 → v7 → v9
         └─ 工业/生态分叉
              v5 / v8 / YOLO11（Ultralytics 工程线）
              v6（美团工业部署线）
              v10（清华端到端 NMS-free）
              v12 / v13（注意力 / 超图社区线）
              v14（跨域非理想成像，论文筹备中）
```

| 主线 | 版本 | 核心命题 |
|------|------|----------|
| 统一回归检测 | v1–v3 | 单阶段、多尺度、速度优先 |
| Bag-of-Freebies | v4–v7 | 训练技巧 + 高效块，推理不加价 |
| 工程产品化 | v5 / v8 / YOLO11 | 易用、缩放族、多任务导出 |
| 工业可部署 | v6 | 重参数化、量化、吞吐 |
| 信息与端到端 | v9–v10 | PGI 可靠梯度；去 NMS |
| 注意力/高阶相关 | v12–v13 | Area Attention；超图 HyperACE |
| 跨域成像 | v14 | 鱼眼/游戏/无人机/全景统一框架 |

## 1. 一览表：每代「相对前代」的具体改进

| 版本 | 年份 | 相对前代的关键改进（机制） | 主要收益 | 主要代价 / 局限 |
|------|------|--------------------------|----------|-----------------|
| **v1** | 2016 | 检测→单次回归；网格负责框 | 极快、端到端、背景误检少 | 定位粗、同格难多目标、召回弱 |
| **v2** | 2017 | Anchor、维度聚类、σ 偏移、passthrough、多尺度训练 | 召回↑、定位↑、VOC/COCO 精度↑ | 仍偏单尺度头；小目标有限 |
| **v3** | 2018 | Darknet-53；三尺度预测；多标签 | 小目标↑、类别扩展 | 相对两阶段仍偏定位；结构渐复杂 |
| **v4** | 2020 | CSP、PAN、Mosaic、CIoU、BoF/BoS 体系化 | 速度—精度新平衡；训练技巧成体系 | 模块多，调参面变大 |
| **v5** | 2020 | PyTorch 工程化；C3/SPPF；n/s/m/l/x；导出一体 | 易用、复现、落地门槛低 | **无正式论文**；经典仍 anchor-based |
| **v6** | 2022 | RepVGG/CSPStackRep、高效解耦头、TAL、量化 | 工业吞吐与 INT8 友好 | 重参数化与量化需配套训练 |
| **v7** | 2022 | E-ELAN、concat 复合缩放、RepConvN、lead 引导分配 | COCO 从零训练 SOTA；推理不加价 | 辅助头/分配理解成本高 |
| **v8** | 2023 | C2f、anchor-free 解耦头、DFL、多任务 | 现代默认范式；自定义数据更稳 | 无正式论文；默认仍要 NMS |
| **v9** | 2024 | **PGI** + **GELAN** | 可靠梯度、参数利用率↑；从零强 | 训练图更复杂（辅助可逆分支） |
| **v10** | 2024 | **一致双分配 → 推理 NMS-free**；CIB/PSA 等 | 真·端到端延迟；参数更省 | 一对一头需与一对多对齐；部署栈需适配 |
| **YOLO11** | 2024 | C3k2、C2PSA；更少参数更高 mAP | Ultralytics 稳定多任务基线 | 无正式论文；默认仍 NMS |
| **v12** | 2025 | Area Attention + R-ELAN + FlashAttention | 注意力进实时区，N 档 AP 再升 | 训练不稳/显存/CPU 慢风险（生产慎用） |
| **v13** | 2025 | HyperACE + FullPAD + DS 轻量块 | 高阶多对多相关；复杂场景↑ | 结构更重；复现/生产收益存疑 |
| **v14** | 2025+ | 跨域管线：域自适应、可变形注意力、多视角/全景 | 非理想成像统一框架 | **无正式论文**；COCO 表不全；非刷榜主线 |

## 2. 按技术维度横向对比

### 2.1 检测范式

| 维度 | 早期 (v1–v3) | 中期 (v4–v7) | 现代 (v8+) | 端到端 (v10) |
|------|--------------|--------------|------------|--------------|
| 阶段 | 单阶段 | 单阶段 | 单阶段 | 单阶段 |
| 锚框 | v1 无；v2–v5 有锚 | 多有锚 / YOLOX 系无锚影响 | **主流无锚** | 无锚 |
| 头结构 | 耦合 | 渐解耦（v6） | **解耦 + DFL** | 双头（训一对多 / 推一对一） |
| 后处理 | NMS | NMS | NMS | **可无 NMS** |
| 标签分配 | 规则/IoU | SimOTA / TAL / lead 引导 | TAL 系 | **一致双分配** |

### 2.2 骨干与融合

| 版本 | 骨干块 | 颈部 | 特色 |
|------|--------|------|------|
| v1–v2 | GoogLeNet 风格 / Darknet-19 | 弱 / passthrough | 网格回归 |
| v3 | Darknet-53 | FPN 式多尺度 | 三尺度 |
| v4–v5 | CSPDarknet / C3 | PAN + SPP(F) | 双向融合 |
| v6 | RepBlock / CSPStackRep | Rep-PAN | 重参数化部署 |
| v7 | E-ELAN | PAN 系 | concat 复合缩放 |
| v8 | **C2f** | SPPF + PAN | 特征复用强 |
| v9 | **GELAN** | 与 PGI 辅助配合 | 梯度路径规划 |
| v10 | 精简 + CIB/PSA | 解耦下采样 | 秩引导块分配 |
| YOLO11 | **C3k2** | + **C2PSA** | 参数更省 |
| v12 | **R-ELAN** | Area Attention | 注意力中心 |
| v13 | DS-C3k2 | **HyperACE + FullPAD** | 超图高阶相关 |
| v14 | DeformableA2C2f 等 | 可变形 FPN + 视角条件 | 跨域自适应 |

### 2.3 训练侧「免费午餐」演进

| 代际 | 代表技巧 | 是否增加推理成本 |
|------|----------|------------------|
| v4 | Mosaic、CIoU、CmBN、SAT 等 BoF | 否 |
| v5 | 强增广、自动锚框、EMA、导出 | 否 |
| v6 | TAL、VFL、自蒸馏、量化友好训练 | 蒸馏仅训练；量化改变部署 |
| v7 | planned Rep、coarse-to-fine lead 分配 | 否（辅助头推理去掉） |
| v9 | **PGI 辅助可逆分支** | 否 |
| v10 | 双头一致匹配 | 否（推理只留一对一头） |

## 3. 逐代优缺点（精读结论）

### YOLOv1
- **优**：统一回归、极快、全局上下文、泛化强、背景假阳性少。  
- **缺**：定位粗、同 cell 多目标失败、小目标召回低。  
- **改进方向被 v2 接住**：锚框与更好的框参数化。

### YOLOv2
- **优**：召回与定位显著好于 v1；维度聚类；多尺度训练。  
- **缺**：小目标与极密集场景仍不足；表征深度有限。  
- **v3 改进**：更深骨干 + 明确三尺度。

### YOLOv3
- **优**：多尺度成标配；Darknet-53 平衡好。  
- **缺**：相对两阶段精度仍有差距；训练体系未体系化。  
- **v4 改进**：CSP/PAN + BoF/BoS。

### YOLOv4
- **优**：首次系统整理「训练免费 / 推理有价」技巧；实时 SOTA。  
- **缺**：模块组合多，工程门槛仍偏 Darknet。  
- **v5 改进**：同一思想 PyTorch 产品化。

### YOLOv5
- **优**：易用、缩放族、部署链完整；社区最大。  
- **缺**：无正式论文；经典检测头偏旧（有锚耦合）。  
- **v8 改进**：无锚解耦 + C2f + 多任务统一包。

### YOLOv6
- **优**：工业 GPU 吞吐、重参数化、量化路径清晰。  
- **缺**：与 Ultralytics 生态分立；需懂 Rep/QAT。  
- **对照**：精度竞赛看 v7/v9；产线 INT8 看 v6。

### YOLOv7
- **优**：trainable BoF 典范；E-ELAN；从零 COCO 强。  
- **缺**：分配与 Rep 规划概念偏学术。  
- **v9 改进**：从「梯度路径块」升级到「可编程梯度信息」。

### YOLOv8
- **优**：现代默认结构；多任务；自定义数据友好。  
- **缺**：无论文；仍依赖 NMS；非最极限参数效率。  
- **后续分叉**：效率/端到端→v10；官方稳→YOLO11；理论→v9。

### YOLOv9
- **优**：直击信息瓶颈；PGI 不增推理；GELAN 参数利用率高。  
- **缺**：训练图更绕；工程多任务不如 v8/11 一体。  
- **v10 改进**：在效率边界上再砍 NMS 与冗余组件。

### YOLOv10
- **优**：NMS-free 端到端；延迟方差小；同精度参数更少。  
- **缺**：生态/多任务广度不如 Ultralytics 全家桶；需验证一对一头质量。  
- **YOLO11 对照**：11 更偏「稳 + 多任务」，不是同一命题。

### YOLO11
- **优**：相对 v8 更准更省；官方长期支持；多任务完整。  
- **缺**：无论文；默认仍 NMS；不是跨域/注意力叙事。  
- **选型**：多数业务默认起点。

### YOLOv12
- **优**：证明注意力可进 YOLO 实时区；小模型 AP 提升明显。  
- **缺**：训练稳定性、显存、CPU 延迟风险；生产不推荐盲上。  
- **v13 改进**：从 pairwise 注意力走向超图高阶相关。

### YOLOv13
- **优**：HyperACE 建模多对多高阶相关；FullPAD 改善全管线信息流。  
- **缺**：复杂度↑；官方/社区对生产收益存疑；复现成本高。  
- **v14 转向**：不再卷 COCO 小数点，改攻非理想成像。

### YOLOv14
- **优**：统一鱼眼/游戏/无人机/全景等跨域问题；模块化变体清晰。  
- **缺**：论文与完整基准表未齐；与 Ultralytics 主线分立；引用需谨慎。  
- **适用**：非标相机与跨域场景，而非通用 COCO 刷榜。

## 4. 「具体改进」因果链（相邻代）

```text
v1 网格回归太粗、同格冲突
 └→ v2：anchor + 聚类 + σ 中心 → 召回/定位↑

v2 小目标弱、语义浅
 └→ v3：更深骨干 + 三尺度 → 小目标↑

v3 训练体系零散、融合弱
 └→ v4：CSP/PAN + Mosaic/CIoU 等 → 精度速度双升

v4 工程难用
 └→ v5：PyTorch + 缩放族 + 导出 → 落地爆发

v5 头偏旧、工业量化不足
 ├→ v6：Rep + 解耦 + TAL + 量化 → 产线吞吐
 └→ v7：E-ELAN + lead 分配 + RepConvN → 从零 SOTA

v5/v7 有锚或训练复杂 vs 产品需求
 └→ v8：C2f + 无锚解耦 + DFL + 多任务 → 现代默认

v8 深层信息损失、仍要 NMS、参数仍冗余
 ├→ v9：PGI/GELAN → 可靠梯度、参数利用率
 └→ v10：双分配去 NMS + 整体精简 → 端到端延迟

v8 工程迭代
 └→ YOLO11：C3k2/C2PSA → 更准更省的官方基线

CNN 建模上限质疑
 └→ v12：Area Attention → 实时注意力
      └→ v13：HyperACE/FullPAD → 高阶相关

标准针孔假设失效
 └→ v14：跨域自适应管线 → 非理想成像
```

## 5. 怎么选（实操）

| 需求 | 更合适的版本 | 理由 |
|------|--------------|------|
| 学习 YOLO 思想 | v1→v3→v4 | 概念递进最清晰 |
| 通用业务检测/分割/姿态 | **YOLO11**（或 v8） | 生态、文档、多任务、稳定 |
| 要极限 GPU 吞吐 / INT8 | **YOLOv6** | 工业重参数化与量化 |
| 要学术从零训练 / 梯度理论 | **v7 / v9** | BoF 与 PGI |
| 要去掉 NMS、压端到端延迟 | **YOLOv10** | 一致双分配 |
| 研究注意力实时化 | v12（实验） | 非默认生产 |
| 复杂场景高阶关系 | v13（实验） | 注意复现与成本 |
| 鱼眼/游戏/无人机/全景 | **YOLOv14** | 跨域命题，不是 COCO 替代 |

## 6. 数字对照时的阅读规则

1. **同论文内的相对提升**（如「相对 YOLOR-CSP −43% 参数 +0.4 AP」）可信度最高。  
2. **跨版本绝对 AP** 只能看趋势：大致从 v1 VOC 时代 → COCO 50%+ 实时档 → N 档约 37–41%（640）。  
3. **v5 / v8 / YOLO11 / v14** 无或弱论文约束时，以官方文档 / README 为准，并标注来源。  
4. Ultralytics 对 **v12 / v13** 的生产警告，选型时应优先于单篇论文的峰值表。

## 结论（直接回答）

**可以清晰对比。**  
已有译本足够支撑三层对照：

1. **机制层**：锚框→无锚、耦合→解耦、NMS→NMS-free、CNN→注意力/超图、标准成像→跨域。  
2. **改进层**：每一代几乎都对准前代 1–2 个明确痛点（见第 4 节因果链）。  
3. **优劣层**：速度、精度、易用、部署、稳定性、场景覆盖不可同时最优——按第 5 节选型即可。

若需要，可再补一版「仅 COCO 同规模 N/S/M 数字汇总表」（附硬件与是否含 NMS 脚注）。
