# YOLO 对比表（交付版）

本目录提供两张可直接用于工作沟通的表格，数据来源分开、互不混排。

| 文件 | 内容 | 建议用途 |
|------|------|----------|
| `表1-机制演进对比.csv` / `.xlsx` Sheet1 | v1–v14 优点 / 缺点 / 相对前代改进 | 方法调研、方案评审、知识沉淀 |
| `表2-ODverse33多域横比.csv` / `.xlsx` Sheet2–3 | v5–v11 多域公平横比数值 | 选型论证、汇报数据附录 |
| `YOLO对比表.xlsx` | 上述两表合一（3 个工作表） | **对外交付首选** |

## 推荐输出形式（工作规范）

1. **对内评审 / Git 协作**：Markdown + CSV（版本可 diff）。
2. **对外汇报 / 跨团队**：`.xlsx`（可筛选、可贴进 PPT/Word、可再导出）。
3. **不要混源**：机制表述（表1）与 ODverse33 数值（表2）分表存放；COCO 厂商表若需另附，再开第三表。

## 数据边界

- **表1**：综合论文/文档阅读的机制对比（见 `../YOLO系列总表.md`），非同一实验协议下的精度排名。
- **表2**：仅引用 ODverse33（arXiv:2502.14314）在统一训练设定下的结果；覆盖 YOLOv5–YOLOv11，不含 v12+/YOLO26。
- 表2 评测跟 COCO 式置信度扫描，数值可能低于各仓库默认展示。
