# YOLO 对比表（交付版）

本目录分源存放多张表，**勿把不同论文数字拼成单一总排名**。

| 文件 | 内容 | 建议用途 |
|------|------|----------|
| `表1-机制演进对比.csv` | v1–v14 优点 / 缺点 / 相对前代改进 | 方法调研、方案评审 |
| `表2-ODverse33多域横比.csv` | v5–v11 多域公平横比 | 选型论证（第三方统一协议） |
| `表3-v12论文COCO自报.csv` | v12 论文 Table 1 摘录 | 论文自报横向补充 |
| `表4-v13论文COCO自报.csv` | v13 论文 Table I 摘录 | 论文自报横向补充 |
| `表3-4速览-v11至v13.csv` | 同档位对照速览 + 跨文差异提示 | 汇报一页纸 |
| `YOLO对比表.xlsx` | 以上合一 | **对外交付首选** |
| `对比表-可读版.md` | Markdown 预览 | GitHub / IDE 阅读 |

## 推荐输出形式（工作规范）

1. **对内评审 / Git 协作**：Markdown + CSV（版本可 diff）。
2. **对外汇报 / 跨团队**：`.xlsx`（可筛选、可贴进 PPT/Word）。
3. **不要混源**：表1 机制 ≠ 表2 ODverse33 ≠ 表3/4 论文自报 ≠ Ultralytics 文档表。

## 数据边界

- **表1**：机制综述，非同协议数值横比。
- **表2**：ODverse33（arXiv:2502.14314）；仅 v5–v11。
- **表3**：YOLOv12 论文自报（arXiv:2502.12524）；T4 TensorRT FP16。
- **表4**：YOLOv13 论文自报（arXiv:2506.17733）；同设定叙述下的对照；**文内 v12 数字可低于 v12 原文**，故设速览表提示。
- **v14**：尚无完整公开 COCO 横表，未单列数值表。
- Ultralytics 对 v12/v13 有生产谨慎提示；引用请标注「作者自报」。
